数据来源与统计口径

固定 broker_id=rwaperp_xyz。成交来自 dashboard/orderly/by-broker；资金流来自 dashboard/fund-flows/by-broker；用户快照来自 metrics/dex-users。每次查询读取公开接口，不保存账户明细。

总成交量为接口 total_volume（Maker + Taker 账户侧口径）。用户快照仅提供最近窗口统计，不随日期筛选重算。未将每日活跃账户相加作为周期去重人数。

资金接口字段为 deposits_usd / withdrawals_usd / net_flow_usd，在确认 USDC 计价口径前保留 USD 标签。日期缺失或接口失败显示缺失，不能视为零。API 日期边界在客户端按所选日期再次过滤。

CMC 持仓为当前快照，采用指数价格估值，历史与逐仓覆盖未确认。缓存缺失可能返回零，全零时显示待核实而非真实零 OI。RWA 分类与非 RWA 差额仅使用 MD 同源数据，每日费用使用 Data API broker_fee_usd。当前页不提供历史 OI、TVL、保证金或资金用户数，避免使用全平台指标代替 RWA Perp。加载时间不等于数据最新业务时间。选择当日可能得到未完成数据。
